Seu app com Dockerfile está no ar

A plataforma encontrou um Dockerfile na raiz e o construiu como ele é: o que ele monta é o que roda. Esta página é o nginx servindo um arquivo estático.

O que todo Dockerfile aqui precisa

  • Escutar na porta de $PORT (8080, a menos que você mude a porta do serviço).
  • Escutar em 0.0.0.0, nunca só em localhost.
  • Gravar o que precisa durar no Object Storage ou num banco: o disco do container começa vazio a cada deploy.

Próximos passos

  1. Torne o código seu: no console, abra este projeto e siga “Seu código” para copiá-lo para o seu GitHub e conectá-lo.
  2. Troque o Dockerfile pelo do seu app e faça push: cada push faz o build e o deploy, sem tirar o serviço do ar.
  3. Adicione o seu domínio no serviço web, em Domínios.
