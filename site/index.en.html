Your Dockerfile app is live

The platform found a Dockerfile at the root and built it as it is: what it builds is what runs. This page is nginx serving a static file.

What every Dockerfile here needs

  • Listen on the port in $PORT (8080 unless you change the service's port).
  • Listen on 0.0.0.0, never only on localhost.
  • Write files that must last to Object Storage or a database: the container's disk starts empty on every deploy.

Next steps

  1. Make the code yours: in the console, open this project and follow “Your code” to copy it to your GitHub and connect it.
  2. Replace the Dockerfile with your app's, then push: every push builds and deploys, with no downtime.
  3. Add your own domain on the web service, under Domains.
